
Weather Application

A clean, responsive, and dynamic Weather Application that provides real-time weather updates based on user location or searched cities. The application features a dynamic user interface that changes its background and icons based on the current weather condition (Clear, Clouds, Rain, Snow, or Thunderstorm).

🚀 Features

• Real-Time Weather Data: Fetches up-to-date temperature, humidity, wind speed, and weather descriptions.
• Dynamic Visuals: UI themes and imagery automatically adapt to match current weather states (e.g., sunny, rainy, snowy).
• City Search: Allows users to search for weather details of any city globally.
• Responsive Design: Optimized for seamless viewing across mobile, tablet, and desktop devices.
